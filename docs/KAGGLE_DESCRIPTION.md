# BatterySurAD: Reflective Battery Surface Anomaly Detection (Core Release)

This dataset provides original images of reflective pouch-type lithium-ion battery surfaces with LabelMe JSON annotations organized across 4 defect types, 2 views, and 15 spatial zones. It accompanies the published BatterySurAD research paper.

**Release scope:** This is a core/original-image release, not the entire augmented image collection reported in the paper. Source archive inventory found 5,909 original image filenames and 5,916 original JSON filenames; pairing and total coverage are not fully verified. Download the numbered ZIP shards and extract to use original paths.

**Reproducibility:** Experiment results in the paper were obtained with a larger dataset. The augmented images and an exact reproduction recipe are not provided in this version. The core release may therefore not reproduce every reported experiment as-is.
